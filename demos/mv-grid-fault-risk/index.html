What This Project Does

The project scores the probability of a fault on medium-voltage grid assets over the next 30 days and assigns a risk band (low, watch, high, critical). It is an independent portfolio project, not an Enel system.

Training: a scikit-learn HistGradientBoostingClassifier, evaluated on a time-based split (older data for training, the most recent window for testing) with ROC AUC, PR AUC and F1. Runs and parameters are logged with MLflow, and a GitHub Actions workflow, started manually, runs the training.

Serving: a FastAPI service packaged with Docker. The live endpoint used by the demo below returns a transparent rule-based score (model_source: rule-based-v1.1), not the trained model.

Scope: a portfolio demonstration, not a production system.
